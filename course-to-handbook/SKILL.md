# 课程资料 → 系统化学习手册

## 适用场景
用户有一套课程资料（课件 PDF、视频字幕 `.srt`，可能还有视频或音频），希望提取知识点形成一本**完整、通俗、结构化、可查阅**的 Markdown 学习手册。重点不是速记，而是覆盖全书知识体系、方便随时温习。手册**每章末尾自带独立的「📌 备忘快贴」**：快贴供 30 秒快速复习，正文供完整阅读。

## 第零步：材料盘点与策略路由（进入目录先做这个）
列出目录里实际有的材料（`srt / mp4 / mkv / m4a / mp3 / pdf` 各多少个、分布在哪层子目录），然后按下表选策略：

| 材料组合 | 策略 |
|---------|------|
| 仅字幕 SRT | **策略 S（仅字幕）**：标准流程，第 1–5 步 |
| 字幕 + 音频 (m4a/mp3) | **策略 S+**：标准流程；字幕**缺失或损坏**的小节，用 `scripts/transcribe_local.py` 基于音频离线重转写修复（见「本地转写修复」节） |
| 字幕 + 视频 (mp4/mkv) | **策略 V（图文笔记）**：标准流程 + ffmpeg 抽候选关键帧 + 视觉审阅精选「有意义」帧，图文穿插成手册 |
| 字幕 + 视频，但用户明确**不要图文** | **逐级降级**：先降为「字幕+音频」策略（视频当音频源用，仍可修复损坏字幕）→ 音频也没有则降为「仅字幕」策略。降级时告知用户当前所处策略 |
| 字幕损坏且无音视频 | 如实标注「字幕损坏无法还原内容」，仅保留标题方向，**不虚构内容** |

**损坏判定**：直接跑审计脚本（只读，不修改文件）：

```bash
"<python 绝对路径>" <本skill>/scripts/audit_srt.py <字幕目录> --json <工作目录>/srt_audit.json
```

- 判定规则：0 字节 / 无有效文本行 → `empty`；不可辨识字符占比 >30% 或大量超长重复（整句循环刷屏）→ `garbled`；有效行 ≤3 → `short`（疑似截断）。退出码 0=全部健康、1=存在损坏、2=目录不存在。
- 已验证：能准确识别真实损坏样本（Latin-1 乱码、"不经常，没有写出来的写文"式整句循环、0 字节），对正常中文/英文字幕零误报。
- 损坏清单在 `srt_audit.json` 的 `damaged` 字段；随后建立「损坏小节 ↔ 音频/视频文件」映射（文件名注意全角/半角引号、句号差异，规范化后再匹配）。

## 本地 Whisper 转写修复（策略 S+ / 降级时）
用**封装好的脚本**，不要手写 worker（已含模型定位、断点续传、失败重跑判断）：

```bash
# 转写单个文件或整个目录（递归，输出同名 .srt；已存在的默认跳过=断点续传，--force 覆盖）
"<python 绝对路径>" <本skill>/scripts/transcribe_local.py <音频或视频路径> [-o 输出目录] [--language zh|en|None]
```

脚本内建的关键保障（踩坑沉淀，勿绕过）：
1. **模型全自动离线定位**：按 `--model 显式路径` → `$HF_HUB_CACHE`/`$HF_HOME` → `D:/software/ai-models/huggingface/hub` → `C:/Users/ysq/.cache/huggingface/hub` 顺序找 `models--Systran--faster-whisper-small` 快照（校验 model.bin >100MB，排除 0 字节占位）；找不到就退出提示先跑 `tools_download_model.py`，**绝不自动联网**。
2. **faster-whisper 而非 whisper-cli**：CPU int8 + `cpu_threads=8` + `vad_filter=True`，速度是 whisper-cli 的数倍（实测 116s 音频约 150s 转完）。
3. **并行编排**：大量文件时手动分批，每批一个后台任务/子代理跑同一脚本，各自 `--json` 汇报；0 字节输出或非零退出码视为失败，重跑一次。
4. **如实记录**：重转写后仍是乱码（源音频本身损毁）→ 保留"无法还原"标注，不得编造。
5. **已知坑**：
   - `python` shim 会报 mise "cannot find binary path"，必须用绝对路径如 `D:/software/mise/data/installs/python/3.14.6/python.exe`
   - faster-whisper 依赖已装（1.2.1 + ctranslate2 4.8.2）；缺失时 `"<python>" -m pip install faster-whisper`
   - HuggingFace 下载模型须走可用代理 `http://127.0.0.1:7890`（系统注入的其他代理会 502）；**运行时传字符串 'small' 会触发联网**，必须本地快照路径（脚本已强制）
   - **Windows 非管理员进程建的 HF 快照符号链接是 0 字节占位**：`tools_download_model.py` 下载后已自动把坏链接替换为 blobs 真实副本；手工复制快照时注意同样处理
   - 改写稿里的英文残留词最后统一跑一遍替换清洗

**模型下载**（一次性，模型缺失时才跑）：

```bash
"<python 绝对路径>" <本skill>/scripts/tools_download_model.py   # 默认代理 7890、下到 D:/software/ai-models
```

**产出回填**：转写文本交给子代理改写成中文（主文档 2–4 段 + 章末「📌 备忘快贴」块，格式见标准流程第 3 步，风格对齐既有文档），再按 `## <标题>` 块定位回填源文档。

## 标准流程（策略确定后）

### 1. 探查资源
- 列出课程目录下所有 PDF（课件）与字幕目录（通常命名 `字幕/*.srt`）。
- 用 `pdftotext`（系统自带，路径 `/mingw64/bin/pdftotext`）提取 PDF 文字。
  **关键坑位**：MinGW 版 pdftotext 无法写入 `/tmp`，必须输出到 Windows 路径（如 `D:/pm_extract/chXX.txt`）。命令：
  `pdftotext "<src>.pdf" "D:/pm_extract/chXX.txt"`（字体告警可忽略）。
- PDF 多为幻灯片，文字极少，真实知识在字幕里；PDF 仅作结构提示。

### 2. 解析字幕归属
- SRT 文件名常带排序前缀 + 内层"章-视频"编号（如 `3--[视频]1-2合格的产品经理_ev.srt` 内层是 `1-2`）。按内层编号把文件映射到各章。
- 列出每章对应的 SRT 完整路径。

### 3. 并行分章提取（关键）
- 为每一章启动一个 general-purpose 子代理（Agent 工具，可在一条消息里并行多个），让其读取本章全部 SRT（必要时参考对应 PDF 文本），产出从 `## 第X章 <章名>` 开始的 Markdown 章节，保存到 `D:/pm_extract/chXX_section.md`。
- 给子代理的明确格式要求：
  - 以二级标题 `## 第X章` 开头；按知识模块用 `### `（建议带 `X.Y` 编号）和 `#### `（建议 `X.Y.Z`）逐层展开。
  - **「段落式叙述 + 配合标题的分点」**：先写一段通俗解释，需要细化处再用列表。严禁通篇纯列表、没有叙述。
  - 通俗易懂，多用日常类比/简单案例；**保留**定义、分类、框架、步骤、工具、案例、误区、金句——追求完整覆盖，不压缩。
  - 中文，去掉时间戳与"讲师："前缀；语音转写错误术语要还原（如"差慢→Xmind""外模型→Y模型""雨骨图→鱼骨图""四位导图→思维导图"）。

  - **每章末尾必须以「📌 备忘快贴」块收尾**——紧跟本章最后一个小节之后、下一章 `## ` 之前，一章仅一个。固定格式：
    ```markdown
    **📌 备忘快贴**
    - **速览**：1~2 句口语句概括本章主线
    - **核心知识**：3~6 条圆点，只留必记的定义/分类/步骤/数据/结论
    - **行动启示**：1~2 条读完即可执行的落地建议
    - **金句**：1 句本章最有价值的原话，保留口语感
    ```
    快贴只能从本章正文提炼，不得引入正文没有的新信息；条目宁缺毋滥。它是独立复习块——读者不看正文也能 30 秒过完本章。

### 4. 规范化与组装
- 用 Python 脚本统一编号：把未编号/中文序号的章（常见是第1章中文"一、二、"、工具章无编号）规整为 `X.Y` / `X.Y.Z`，保持全文档一致。
- 脚本负责：①规范化各章标题 ②按顺序拼接 ③自动由标题生成"全书知识地图（目录）" ④在顶部加 `# 文档标题` + 使用说明前言 ⑤写出最终 .md 到用户工作目录。
- 注意：用户要求"一级标题作为文档标题"，故最终文件以 `# 标题` 开头，各章为 `##`。

### 5. 策略 V 附加：抽帧与图文穿插（仅字幕+视频且用户要图时）
- **密集抽候选帧**：每课用 ffmpeg 抽 ~11–30 个时间点（百分比 4%→96%）到 `关键帧_候选/`，命名 `chap<课号两位>_<序号>.jpg`。
- **视觉审阅精选**：子代理批量看图打分，只留「内容完整、无遮挡、能看清知识」的有意义帧；**宁缺毋滥**。
- **穿插与归位**：精选帧移入 `关键帧/`，按知识点穿插进正文（每个知识点 1–3 张），写 `关键帧/映射清单.txt`（帧 ↔ 视频/知识点对应）。
- **抽帧后必抽查**：确认图与所在小节内容对得上。

### 6. 质量抽检
- 抽查 2~3 个章节（一个概念章 + 一个工具章），确认是"叙述+分点"而非纯列表、编号一致、无术语错乱、每章末尾有且仅有一个「📌 备忘快贴」且四要素（速览/核心知识/行动启示/金句）齐全、快贴内容确与正文对应、（策略 V）图片路径有效且图文对应。

## 坑位提醒
- pdftotext 输出路径必须用 Windows 盘符路径，不能用 `/tmp`。
- 规范化脚本对**已经数字编号**的章节要做幂等处理（不要重复加前缀），否则二次运行会破坏编号。
- 子代理产出的章节编号风格可能不一（中文序号 vs 十进制 vs 无编号），组装前务必统一。
- 子代理读大量 SRT 时可能把语音转写错误当真，组装后务必抽检关键术语。
- 快贴与主文档小节标题可能存在全角/半角引号差异，合并/对齐前先规范化引号再匹配。
- 子代理可能漏写「📌 备忘快贴」、写成多个、或插到章中间；组装/规范化脚本要校验：每个 `## ` 章块内有且仅有一个快贴块且位于章末——缺失就按固定格式补写，多余就合并，位置不对就移到章末。

## 产物
- 一个完整的 Markdown 学习手册（如 `产品名入门知识手册.md`），位于用户工作目录；**每章末尾自带「📌 备忘快贴」复习块**（速览+核心知识+行动启示+金句）；策略 V 另附 `关键帧/` 目录与映射清单。
- 手册已原生含章末快贴，一般**无需再合并外部快贴文档**。仅当用户提供旧版独立快贴文档要求合并时：以主文档分类/小节为骨架，每小节组装为 `**快贴速览**`（快贴圆点）+ `**详细解读**`（主文档正文），文件名如 `<名>-合并版.md`；对齐时统一全角/半角引号后再匹配标题，目录用带锚点链接的列表。合并前先检查正文是否已有「📌 备忘快贴」——有则以外来快贴内容替换原块（取并集时去重），避免一章出现两个快贴。

## 配套脚本（本 skill 目录）
| 脚本 | 用途 | 关键参数 |
|------|------|---------|
| `scripts/audit_srt.py` | 字幕损坏审计（只读）：empty/garbled/short 判定 + JSON 报告 | `<字幕目录> [--json out.json]`，退出码 0 健康 / 1 有损坏 |
| `scripts/transcribe_local.py` | Faster-Whisper 本地离线转写（自动定位模型快照、断点续传、失败非零退出） | `<媒体路径> [-o outdir] [--language zh\|en\|None] [--force] [--json out.json]` |
| `scripts/tools_download_model.py` | 一次性下载 faster-whisper-small 到数据盘并修复坏符号链接 | `[--proxy http://127.0.0.1:7890] [--dest D:/software/ai-models/huggingface/hub]` |
